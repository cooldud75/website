# I created this website for $11.86 in two hours using free Google AI

Out of pure curiosity I wanted to see if my last name was available as a domain name. Agosta.com was not available but Agosta.net was and that’s just as good. Then I asked Google Gemini how to buy it, create it, host it, code it, and update it. I paid $11.86 from Cloudflare for Agosta.net, then downloaded Visual Studio Code (VSC), signed up for GitHub, downloaded a couple other random programs and necessary protocols. Soon I was able to literally copy paste code it gave me, and I had a preview of my barebones website. I had to then upload my project to GitHub inside of VSC and link Cloudflare to my GitHub project. And boom right there was my website created with me doing none of the real work. What I imagined would have taken hours of education, collaboration, money, and troubleshooting, I was able to do in no time with no experience all by myself. To me this shows how efficient the future is going to be in all areas of the software industry. Using AI was easy, fast, efficient, and created quality output. Anyone that can use these tools should, despite all the pushbacks and negativity towards AI in general. I liken it to using a calculator while everyone is still using the abacus. You will be left behind if you don’t use what’s available and it is paramount to do so while the iron is hot.
